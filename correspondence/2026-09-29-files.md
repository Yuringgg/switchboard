## ⚠ One manual step for Yuri — Vercel

Opening a file needs **`AZURE_STORAGE_CONNECTION_STRING`** on Vercel (the
console mints the 5-minute links). Until it is set, `/files` lists everything
but opening a file answers 503 with a sentence saying why.

Azure portal → Storage accounts → **swbattachments** → Security + networking →
**Access keys** → key1 **Connection string** → copy. Vercel → the
`switchboard-console` project → Settings → **Environment Variables** → add
`AZURE_STORAGE_CONNECTION_STRING` (Production), save, then **Redeploy**.

The worker got the same value as a Container Apps **secret** via `az` — see
the deploy addendum below.
